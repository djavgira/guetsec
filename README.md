# GUETSEC 官网

桂林电子科技大学信息安全协会（[guetsec.cn](https://)）官方网站，基于 [Docusaurus](https://docusaurus.io/) 构建

## 使用

```shell
# 安装依赖
npm install

# 本地
npm run start

# 构建
npm run build

# 预览
npm run serve
```

## 目录

```text
src/
├── pages/           # 路由页面（首页、团队成员、荣誉奖项、相册、关于）
├── components/      # 公共组件
├── data/            # 数据文件（成员、荣誉）
└── css/             # 全局样式
docs/                # 文档页面
static/              # 静态资源（图片、头像等）
```
